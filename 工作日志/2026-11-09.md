## m3layout 布局助手 + 密度对照页（13:20）

**做了什么**

- 新增 launcher/MMMLauncher/lib/m3layout.aardio（约 250 行）：
  - 尺寸常量集中在文件头：LABEL_W / ROW_H / ROW_STEP / BTN_H / BTN_W / SECTION_H /
    SECTION_GAP / SECTION_SPACE / NOTE_STEP / TEXT_DY；
  - 方法：section / ow / check / 	ext / uttons / gap / inish，
    全部按竖向流式排，调用方只描述「放什么」；
  - 内部用 winform.add 的**单控件形式**创建（该形式直接返回控件对象，
    见 lib/win/ui/_.aardio:1879-1884），坐标走逻辑像素，DPI 由 aardio 处理；
  - 按 cls 自动套 m3theme（static→note、edit→field、checkbox→bgcolor、plus→button）；
  - opt 可覆盖尺寸，便于同一窗口并排比较两种密度。

  左边紧凑（行高 24 / 行距 30 / 标签列 64），右边默认（28 / 36 / 88），
  底部显示两边各排到多少 	op。

**为什么**

- 用户指出：我写 HTML 好看、写 winform 常常难看。诊断结论是缺两样东西——
  **自动布局**和**渲染反馈**。前者能靠这层助手补上，后者只能靠用户截图。
- 用户给了 MultiMC 的设置界面截图，要求「参考布局、先不照抄分区」。
  所以只借骨架：左导航列表 + 右侧内容 + 小节标题 + 整行控件 + 右下按钮。

**踩坑**
