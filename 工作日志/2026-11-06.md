**为什么**

- 用户要"大改界面"，需要一个能整体回退的点。

  - 分支 → 直接 `git checkout` 过去对比或继续开发；
  - zip → 不依赖 git 也能拿到完整源码与可执行文件。

**恢复方式（写给以后的自己）**

```bat

:: 方式二：切到备份分支（master 的改动会留在原分支）
git checkout backup/ui-before-redesign

:: 方式三：只把某个文件恢复成基线版本
git checkout ui-baseline-2026-11-06 -- launcher/MMMLauncher/lib/m3theme.aardio

:: 方式四：不依赖 git，解压 _backup\MMML-source-2026-11-06.zip
```
