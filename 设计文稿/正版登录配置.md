# 正版登录（微软）配置

> 微软登录需要**本项目自己的 Azure 应用 ID**。
> 不能借用其他启动器的 ID：那是别人的凭据，可能随时被吊销。

## 一、注册应用（一次性，约 3 分钟）

1. 打开 <https://portal.azure.com>，用**要登录 Minecraft 的那个微软账号**登录
2. 进入 **Microsoft Entra ID** → 左侧 **应用注册** → **新注册**
3. 填写：
   - 名称：`M3L Launcher`（随意）
   - 受支持的帐户类型：**仅个人 Microsoft 帐户**（Consumers）
   - 重定向 URI：**留空**
4. 创建后，在概览页复制 **应用程序(客户端) ID**，形如
   `1a2b3c4d-1234-5678-9abc-def012345678`
5. 左侧 **身份验证** → 拉到底部 **允许公共客户端流** → 选 **是** → 保存
   （设备码流程必须打开这一项，否则会报 `unauthorized_client`）

## 二、填到启动器

- 设置 → 启动器设置 → 「微软客户端 ID」
- 或者直接改 `config.json` 的 `ms_client_id`

填一次就行，之后登录不需要再填。

## 三、常见错误

| 错误 | 原因 |
|---|---|
| `AADSTS700016` | 客户端 ID 不存在 / 用了别人的旧 ID |
| `unauthorized_client` | 没打开「允许公共客户端流」 |
| `AADSTS7000218` | 应用类型不对（必须是「个人 Microsoft 帐户」） |
| XSTS `2148916233` | 这个微软账号还没建 Xbox 档案，先去 xbox.com 建一个 |
| XSTS `2148916238` | 账号被判未成年，需要加入家庭组 |
| XSTS `2148916235` | 账号所在地区不支持 Xbox Live |

## 四、为什么不做成"开箱即用"

微软的设备码流程要求 `client_id` 属于某个已注册的应用。把它写死在源码里只有两种结果：

1. 用**别人的** ID —— 不合规，且对方一改配置全体失效；
2. 用**自己的** ID —— 必须自己注册一次。

本项目选择第 2 种：ID 存在配置里，不进仓库。

## 五、403 `Invalid app registration`：应用要被 Minecraft 列入允许名单

配置全对、浏览器也显示登录成功，但换 Minecraft token 时报：

```
Minecraft 认证失败：Invalid app registration,
see https://aka.ms/AppRegInfo for more information
```

**这不是配置错误。** `api.minecraftservices.com` 只接受**在允许名单里**的
Azure 应用 ID，第三方启动器必须提交申请、等官方审核通过。

### 申请方式

1. 说明页：<https://help.minecraft.net/hc/en-us/articles/16254801392141>
2. 表单（就是这个页面里给的「应用注册 / AppID」表单）：
   <https://forms.cloud.microsoft/Pages/ResponsePage.aspx?id=v4j5cvGGr0GRqy180BHbR-ajEQ1td1ROpz00KtS8Gd5UNVpPTkVLNFVROVQxNkdRMEtXVjNQQjdXVC4u>
3. 要填：应用名称、**客户端 ID**、用途说明、联系方式。
4. 通过后会收到一封来自 Mojang 的邮件，确认应用已在允许名单里。

### 收到通过邮件之后

不需要改代码 —— 客户端 ID 不变，重新走一次「微软登录」就能拿到 Minecraft token。

### 等待期间能做什么

- **外置登录**（authlib-injector）不受影响，可以先测这一条；
- 离线登录照常可用；
- 白名单是按**应用**批的，不是按用户，所以一次通过、所有用户都能用这个应用登录。

### 表单填写稿

> 表单是 Microsoft Forms（脚本渲染），我这边打不开它的具体字段。
> 下面是按常见问法准备的答案，字段名不一致时按意思对应；
> 遇到拿不准的字段，把截图发我，我按实际问法改。

| 字段（可能的问法） | 填什么 |
|---|---|
| Application name / 应用名称 | `M3L Launcher` |
| Application (client) ID / 客户端 ID | `d199a26a-6a2b-4480-b5e5-a085d3015ebb` |
| Publisher / 开发者 | `MFn`（个人） |
| Application type / 类型 | Desktop launcher（Windows 桌面启动器） |
| Distribution / 是否公开 | Public，免费、非营利 |
| Website / Source code | 项目的公开地址（见下方说明） |
| Redirect URI | `不适用：使用设备码流程，没有回调` |
| Contact email | 你自己的常用邮箱（能收 Mojang 通知的那个） |
| Data collected / 数据处理 | 只在本地保存令牌，不上传任何用户数据 |

**英文描述（可直接粘）**

```
M3L Launcher is a lightweight, non-commercial Windows launcher for
Minecraft: Java Edition. Users sign in with their own Microsoft account
via OAuth 2.0 device code flow; the launcher then starts the game they
already own. It does not distribute Minecraft, does not bypass ownership
checks, does not collect telemetry, and stores tokens only on the user's
own machine.
```

**中文描述**

```
M3L Launcher 是一个轻量的 Windows 平台 Minecraft Java 版启动器，
仅供用户登录自己已购买的账号并启动游戏。使用微软 OAuth 2.0 设备码流程，
不分发游戏本体、不绕过拥有权校验、不收集任何用户数据，
登录令牌只保存在用户本机。
```

**注意**

- 表单里如果有「网站 / 源码地址」，最好填一个真实可访问的页面
  （仓库地址或项目主页）。没有的话，先把仓库传上去再提交，否则容易被退回。
- 提交后留意邮箱（包括垃圾箱）。通过时会收到 Mojang 的确认邮件。
- 白名单按**应用**生效，不需要每个用户各自申请。
