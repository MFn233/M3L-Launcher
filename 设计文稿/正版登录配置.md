# 正版登录（微软）配置

> 微软登录需要**本项目自己的 Azure 应用 ID**。
> 不能借用其他启动器的 ID：那是别人的凭据，可能随时被吊销。

## 一、注册应用（一次性，约 3 分钟）

1. 打开 <https://portal.azure.com>，用**要登录 Minecraft 的那个微软账号**登录
2. 进入 **Microsoft Entra ID** → 左侧 **应用注册** → **新注册**
3. 填写：
   - 名称：`M3L Launcher`（随意）
   - 受支持的帐户类型：**仅个人 Microsoft 帐户**（Consumers）
   - 重定向 URI：**留空**
4. 创建后，在概览页复制 **应用程序(客户端) ID**，形如
   `1a2b3c4d-1234-5678-9abc-def012345678`
5. 左侧 **身份验证** → 拉到底部 **允许公共客户端流** → 选 **是** → 保存
   （设备码流程必须打开这一项，否则会报 `unauthorized_client`）

## 二、填到启动器

- 设置 → 启动器设置 → 「微软客户端 ID」
- 或者直接改 `config.json` 的 `ms_client_id`

填一次就行，之后登录不需要再填。

## 三、常见错误

| 错误 | 原因 |
|---|---|
| `AADSTS700016` | 客户端 ID 不存在 / 用了别人的旧 ID |
| `unauthorized_client` | 没打开「允许公共客户端流」 |
| `AADSTS7000218` | 应用类型不对（必须是「个人 Microsoft 帐户」） |
| XSTS `2148916233` | 这个微软账号还没建 Xbox 档案，先去 xbox.com 建一个 |
| XSTS `2148916238` | 账号被判未成年，需要加入家庭组 |
| XSTS `2148916235` | 账号所在地区不支持 Xbox Live |

## 四、为什么不做成"开箱即用"

微软的设备码流程要求 `client_id` 属于某个已注册的应用。把它写死在源码里只有两种结果：

1. 用**别人的** ID —— 不合规，且对方一改配置全体失效；
2. 用**自己的** ID —— 必须自己注册一次。

本项目选择第 2 种：ID 存在配置里，不进仓库。
