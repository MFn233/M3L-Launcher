# MFn's Minimalism Mclauncher 设计方案
*(别称： M^3 L / M3L / 3ML / MMML)*

> **历史版本。** 本文为 v1，已由 `设计文档v2.md` 取代，不再更新，仅作留档。
> 文中「MIT 协议」为当时的表述；项目现已改为 **GPL-3.0-or-later**。

## 一、关于设计理念

* 极简，无视觉负担、无运行负担。

* 仅支持 Windows 端。

* 精简的同时好用、绿色、portable。

* 正版登录：保证安全性。

* 不以牺牲精简性为代价，发挥可自定义性、美观性。

* 启动器分为三个部分：Launcher、Downloader、Core。

* 启动器图标：主要元素是大写字母M，右上角角标3。

## 二、关于Launcher界面

### 0.界面设计

* 配色只使用黑白。先做一个尝试。

* 后期有可能支持高度自定义。所以很多东西不能写成CONST。

### 1.启动器主页

* 标题，显示“M^3 L”。

* 启动游戏、设置两个按钮。对齐锚点在右下角。

* 更换游戏实例的下拉框，在启动游戏和设置的下下方。鼠标移上去，显示tooltip，内容是完整的版本名（实例名）。

* 一行状态栏。显示当前的状态。包括登录的方式、用户名、版本、分配的内存。可以在设置中开关。

* 启动器可以被随意改变大小。或许未来会加入自定义启动器样式。如果太臃肿或许不会。

### 2.启动游戏按钮按下后

* 弹出日志。日志的开关写在设置当中。日志显示在单独的界面中。

* 一些用户需要启动器在启动后自动隐藏。这一功能也需要可被设置。

* 弹出游戏窗口，游戏窗口的大小应该在设置中可以调整。游戏窗口的大小有三个规则：

>1.玩家手动设置，并提供一个“默认大小”按钮。
>
>2.全屏大小
>
>3.与启动器窗口大小一致。

* 如果 JAVA 版本不匹配，弹出对话框：JAVA版本有误。让用户选择：1.更换推荐的JAVA版本（启动器自动选择）2.手动重新选择JAVA（弹出JAVA管理界面）3.强制使用这个JAVA启动游戏。如果所有推荐的java都被加入了黑名单，那么需要提示，并告诉用户使用了什么JAVA启动游戏。

* 需要提供一个在启动器中强制杀掉游戏进程的按钮，在启动后显示。目前的想法是：启动后在状态栏里提示“右键启动游戏按钮可强制停止游戏进程”，并实现此功能。

### 3.设置按钮按下后

* 显示设置界面。

* 游戏设置：用户配置（并在旁边显示当前用户名与登录方式）、分配内存（一个滑条，一个输入框，一个“自动配置”按钮。）、游戏窗口大小、JAVA选择（输入框、JAVA管理入口）、游戏路径选择（输入框、游戏版本路径管理入口）

* 启动器设置：启动时弹出日志窗口、启动后隐藏启动器、主页状态栏开关、调试模式、允许多开、游戏进程优先级等。

* JAVA管理：自动检测多个JAVA版本，并列出，允许用户选择、手动添加、将某个版本加入黑名单。允许用户重新检测并自动更新列表。加入黑名单后，此目录的JAVA版本前显示“[黑名单]”字样。被设为当前JAVA后，也应在此JAVA版本前显示“[当前]”。JAVA路径管理界面应当可以左右横向划动，但JAVA版本黏着在最左侧不动。

* 游戏版本路径管理：自动检测正版游戏目录并添加。允许用户添加多个.minecraft所在的路径，并列出。允许用户选择、手动添加、删除，并自定义每个版本路径在启动器界面中的命名。值得注意的是不应允许用户删除正版游戏目录。用户选择某个路径之后，在一级设置界面的版本目录相应地也会更新。官方目录显示“[官方]”，当前目录显示“[当前]”，都应该显示在路径前面。

* 用户配置：按下后弹出用户配置界面。暂时只支持离线登录。后续添加关于正版登录与外置登录的支持。在此界面中，允许用户管理多个账号（添加、删除），对于离线账户，支持更改UUID。

## 三、关于Downloader

### 0.设计理念

* 忠实于MMML的设计，保持界面简洁且易用，尽量不加冗余元素。

* 只下载，没有其他功能。

* 分为CORE和GUI，与Launcher和core的关系一致。

### 1.要做的事

* 下载和验证版本完整性，不做其他事。

* 链接modrinth、curseforge、MCMOD百科等平台，支持下载里面的内容（整合包、mod、资源包、光影）。支持跳转MCMOD百科看关于mod或整合包的条目（如果有的话就显示，没有就不显示）。
* 支持自动/手动安装MOD加载器。

* 支持镜像源的切换。

* 支持p2p下载，快速且专一。

* 下载完成后在版本目录写入边车文件 `.m3l.json`，记录这次下载的确定信息：

```json
{
    "game": "1.20.1",
    "loader": "Fabric",
    "loader_version": "0.19.3",
    "source": "mmmd"
}
```

  启动器只在**存在**该文件时采信它（下载器写入的比任何推断都可靠）；没有就按版本 JSON 推断。
  边车不参与启动，纯元数据，删掉也能玩。

## 四、关于Core

### 0.设计理念

* 只做一件事：接收参数 → 找Java → 拼命令 → 启动Minecraft进程 → 返回PID或错误码。不管下载，不管其他内容。

* 代码努力做到整洁且易懂。

* 可以被其它人写GUI调用，而不是只能用MFn写的GUI。也可以允许别人写TUI、CUI操作。

* 多种存在形式：命令行exe，DLL，aardio用户库……

### 1.工作方式

* 参数：
```
--game-dir --version --username --memory --java --work-dir 
--uuid --access-token --user-type --version-type
--width --height --log-file --no-wait --dry-run --help
```

* 退出码 0 成功 / 1 参数 / 2 Java / 3 版本·库·natives / 4 启动失败或游戏异常退出。

* 配置文件 config.txt（纯文本键值对，和 exe 同目录）：username / memory / game_dir / version / java / width / height。
