# M^3 L（MMMLauncher）发布说明

## 0.1.0 — 首个测试版

发布日期：2026-10-31

### 功能

**主页**

- 一键启动当前版本，支持多开（可同时跑多个实例）
- 版本下拉框直接切换版本；名字过长时状态栏用 `…` 省略，悬停显示完整名字
- 状态栏显示：登录方式 · 用户名 · 版本 · 分配内存
- 每个实例一个独立日志窗口，错误行标红；右键「启动游戏」强制结束所有实例

**设置**

- 用户配置：多账号管理（添加 / 删除 / 设为当前），离线账号可自定义 UUID
- 分配内存：滑条 + 手动输入 + 自动配置
- 游戏窗口：手动 / 全屏 / 与启动器一致
- Java：自动扫描（`JAVA_HOME`、MC runtime、常见安装目录、PATH），可添加 / 移除 / 黑名单 / 设为当前
- 游戏路径：多路径管理，切换后版本列表跟着换
- 版本管理：设为当前 / 切换版本隔离 / 重命名 / 删除（删除进回收站，可恢复）
- 进程优先级：低 / 低于正常 / 正常 / 高于正常 / 高
- 启动器：启动时弹日志、启动后隐藏、显示状态栏、调试模式、允许多开

### 已知问题

- 客户端本身的问题不算启动器的锅：测试用的 Fabulously Optimized 实例在 Distant Horizons 里崩溃
- 高 DPI（125% / 150%）还没有专门验证过
- 实时（Realtime）优先级没有提供，避免把系统拖死
- 图标还是 aardio 默认图标
- 正版登录 / 外置登录 / 模组下载（MMM-DL）都还没做

### 发布步骤（在 aardio IDE 里）

1. 打开 `launcher/MMMLauncher/default.aproj`
2. 确认「工程属性」里的版本号是 `0.1.0.0`、输出名 `MMMLauncher.exe`
3. 发布（工程菜单 → 发布，或工具栏发布按钮），输出到 `/dist/`
