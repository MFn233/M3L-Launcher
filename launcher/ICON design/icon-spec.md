# M^3 L 图标规格（基于 v2 round）

作者原稿：`v2 round.svg` / `v2 round.png`（128 视口，`rx=64` 的白色圆盘 + 黑色 M³）。
成品：`MMMLauncher.ico`（7 档），由 `..\图标设计\build_ico_raw.py` 从原 PNG 生成。

## 几何

| 项 | 值 |
|---|---|
| 画布 | 正方形，图标铺满 |
| 圆盘直径 | **画布的 94%**（留 3% 边距，避免贴边发挤） |
| 圆盘颜色 | `#FFFFFF`，四角 alpha=0 |
| 字色 | `#000000` |
| 大尺寸字迹（M³ 整体）宽度 | **圆盘直径的 62%**，水平垂直居中 |
| 小尺寸字迹 | **只留 M**（去掉 ³），M 高度 = 圆盘直径的 66% / 60% / 60% |

## 各档尺寸用哪套字

| 尺寸 | 内容 | 原因 |
|---|---|---|
| 256 / 128 / 64 / 48 | M³（62%） | ³ 能看清，保留完整标识 |
| 32 / 24 / 16 | 只有 M | ³ 在这个尺寸下会糊成一团灰点 |

## ICO 结构

- 7 个条目：256, 128, 64, 48, 32, 24, 16
- 每档 32bpp、PNG 压缩（Vista 起支持）
- **每档单独渲染**，不是从 256 缩放——小尺寸的字重和构图是专门调过的

## 在 SVG 里改的话

- 圆盘：`<rect width="128" height="128" rx="64"/>` → 要 94% 内缩就改成 `x="4" y="4" width="120" height="120" rx="60"`
- 字迹放大到 62%：把 M 和 ³ 两个 `<path>` 用一个 `<g transform="translate(...) scale(...)">` 包起来整体缩放
